Was ist eine M3U IPTV Playlist?

Eine M3U-Datei (Moving Picture Experts Group Audio Layer 3 URL) ist eine Playlist-Datei, die eine Liste von Streaming-URLs enthält. Im IPTV-Bereich enthält jede M3U-Zeile einen Kanal-Stream-Link. Format-Beispiel:

#EXTM3U
#EXTINF:-1 tvg-id="ARD.de" tvg-name="Das Erste" group-title="Deutsch",Das Erste HD
https://stream.example.com/ard-hd/index.m3u8
#EXTINF:-1 tvg-id="ZDF.de" tvg-name="ZDF" group-title="Deutsch",ZDF HD
https://stream.example.com/zdf-hd/index.m3u8

Häufige Fragen zur IPTV M3U Playlist

Was ist eine M3U Playlist?

Eine M3U Playlist ist eine Textdatei mit einer Liste von Medien-URLs – bei IPTV enthält sie Links zu Live-TV-Kanälen. Jede Zeile mit #EXTINF enthält Kanalname und Streaminformation.

Wie öffne ich eine M3U Playlist in VLC?

VLC öffnen → Medien → Netzwerkstream öffnen (Strg+N) → M3U-URL von MOJO4K einfügen → Wiedergabe. Alle Kanäle laden als Playlist.

Was ist der Unterschied zwischen M3U und Xtream Codes?

M3U ist eine statische URL-Liste; Xtream Codes ist ein API-Protokoll (URL + User + Passwort) für dynamische Kanalaktualisierungen und EPG. MOJO4K.DE liefert beides – nutzen Sie je nach App das passende Format.
