Set IPTV einrichten: Set IP TV App auf Samsung, LG und Android

Set IPTV ist eine der bekanntesten Smart-TV-Apps für IPTV. Sie lädt Ihre Playlist über die MAC-Adresse des Fernsehers. Hier lesen Sie, wie das geht und was Sie dafür brauchen.

24h kostenlos testen Preise ansehen

Was ist Set IPTV?

Set IPTV (auch „Set IP TV“ oder „SetIPTV“) ist ein IPTV-Player für Samsung- und LG-Fernseher, der außerdem für Android und einige Set-Top-Boxen erhältlich ist. Die App zeigt beim Start die MAC-Adresse des Geräts an. Über diese Adresse ordnen Sie auf der Website des Entwicklers Ihre Playlist dem Fernseher zu.

Set IPTV ist ein Player: Die App selbst enthält keine Sender, Filme oder Serien. Sie spielt ab, was Sie ihr als Playlist geben, also einen M3U-Link oder (wenn die App es unterstützt) einen Xtream-Codes-Login Ihres IPTV-Anbieters. Wie gut das Bild ist und wie stabil Sender laufen, hängt deshalb vom Anbieter und von Ihrer Internetleitung ab, nicht von der App.

Set IPTV unterstützt M3U-Playlists mit EPG und bietet Kategorien, Favoriten und eine Kindersicherung. Nach einer Testphase wird eine Aktivierungsgebühr pro Gerät fällig, die direkt an den Entwickler geht.

Was Sie für Set IPTV brauchen

Ein unterstütztes Gerät

Samsung Smart TV (Tizen), LG Smart TV (webOS) oder ein Android-Gerät. Ältere Fernseher finden die App teils nicht im Store.

Die MAC-Adresse

Steht auf dem Startbildschirm der App. Notieren Sie sie genau, Groß- und Kleinschreibung spielt keine Rolle.

Einen IPTV-Zugang

Einen M3U-Link Ihres Anbieters. Ohne ihn zeigt die App nur einen leeren Bildschirm.

Handy oder PC

Zum Hochladen der Playlist auf der Website des Entwicklers.

Set IPTV einrichten: Schritt für Schritt

  1. App auf dem Fernseher oder der Box installieren und einmal öffnen. Auf dem Startbildschirm zeigt sie die MAC-Adresse (bei manchen Apps zusätzlich einen Device Key).
  2. Die Website des App-Entwicklers am Handy oder PC öffnen und den Bereich zum Hochladen der Playlist wählen.
  3. MAC-Adresse (und ggf. Device Key) eintragen, dann den M3U-Link oder die Xtream-Zugangsdaten Ihres Anbieters einfügen.
  4. Speichern, die App am Fernseher neu starten: Die Senderliste wird geladen.
  5. Nach der Testphase der App bei Bedarf die Lizenz auf der Entwickler-Website kaufen. Diese Lizenz bezahlt nur die App, nicht das IPTV-Abo.

Ändert sich später Ihr Zugang, laden Sie den neuen Link auf derselben Seite hoch und überschreiben den alten. Ausführlich mit Bildern: IPTV auf Samsung TV und IPTV auf LG TV.

Häufige Fragen zu Set IPTV

Ist Set IPTV kostenlos?

Set IPTV kann zunächst kostenlos getestet werden, danach ist eine Aktivierungsgebühr pro Gerät fällig. Das IPTV-Abo bezahlen Sie getrennt beim Anbieter.

Wo lade ich die Playlist für Set IPTV hoch?

Auf der Website des Set-IPTV-Entwicklers. Dort tragen Sie die MAC-Adresse aus der App ein und fügen den M3U-Link Ihres Anbieters ein.

Set IPTV zeigt „Playlist not found“, was tun?

Prüfen Sie die MAC-Adresse, laden Sie die Playlist erneut hoch und starten Sie den Fernseher neu. Öffnen Sie den M3U-Link testweise im Browser, um zu sehen, ob der Zugang aktiv ist.

Was ist der Unterschied zwischen Set IPTV und Smart IPTV?

Beide werden per MAC-Adresse aktiviert und bekommen die Playlist über eine Website. Sie unterscheiden sich in Oberfläche, Preis und unterstützten Geräten; die Sender kommen in beiden Fällen vom IPTV-Anbieter.
